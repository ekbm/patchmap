About

Patchmap lists the Windows security fixes Microsoft publishes each month, grouped by the area of Windows they touch, for the Windows versions shown above. Known problems come from two places: Microsoft's own release health pages (collected automatically, labelled "Microsoft"), and problems reported elsewhere that we add by hand with sources (labelled "Patchmap").

Coming next: which files each update changed, and an optional filter for software that depends on Windows features (starting with print management tools).

Not affiliated with Microsoft. Not official advice: always check Microsoft's own pages before acting. Security fix data comes from the Microsoft Security Update Guide.
